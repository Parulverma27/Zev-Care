# Platform Scope Rules

1. **Functionality Changes**:
   - When asked to make functional or logic changes without specifying a target, **always implement the changes for BOTH Web and App**.
   - If a specific platform is explicitly specified (e.g. "for web only" or "for app only"), apply it strictly to that platform.

2. **UI / Styling Changes**:
   - Apply UI / layout / style changes strictly according to what is instructed.
   - If specified for Web, modify the Web layout/styling.
   - If specified for App (mobile / native), modify the App layout/styling.
   - If no specific platform is mentioned, update both Web and App UI consistently.
